# SQL Script Hub

An interactive, minimal blank-page application built with HTML, CSS, and JavaScript.

## Features
- **Blank Page Interface**: Clean, distraction-free environment.
- **Keystroke Triggered**: Type a number and press <kbd>Enter</kbd> to view SQL scripts:
  - `1`: `STUDENT_INFO` table definition, alterations, and records
  - `2`: Query operators (`AND`, `OR`, `NOT`, `LIKE`, `IN`, `BETWEEN`, `ALL`, `ANY`, `EXISTS`, `SOME`)
  - `3`: `STUDENT_DETAILS` aggregate queries (`COUNT`, `SUM`, `MAX`, `MIN`, `AVG`, `GROUP BY`)
  - `4`: `CUSTOMER` table management and `EXISTS` subqueries
  - `5`: `STUDENTS` table and PL/SQL block with `CURSOR` and grading logic

## Getting Started
Open `index.html` directly in any web browser, or run locally:
```bash
node server.js
```
Then visit `http://localhost:3000`.
